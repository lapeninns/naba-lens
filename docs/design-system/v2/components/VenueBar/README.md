# VenueBar

The bar that names the pub you are working in and your role there. It is on every capture and review screen.

- Pub name in full in `heading`; the role line (“You’re staff here”, “You’re a manager here”) in `caption`.
- “Change” appears only when the person belongs to more than one pub. Changing pub during an upload must warn that labels will be cleared.
- You provide: pub name, role, and whether switching is available.
- Don’t truncate the pub name to an abbreviation; wrap to two lines instead.
