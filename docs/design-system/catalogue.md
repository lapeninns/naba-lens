# Component catalogue

This catalogue lists the components built for Common Room, which still ship. Album components (slot tile, album count, place chip, match picker and the rest of `DESIGN.md` §5) are added here as batches A1 to A4 build them.

Every shared component, the layer it belongs to, the name [common-room.md](common-room.md) §4 gives it, and how widely it is used. Check here before building anything: if a row covers the need, extend that component. Counts were taken on 14 Nov 2026; the Progress and PhotoSegments rows were recounted on 15 Nov 2026.

**Files using it** is the number of files under `app/` and `components/` that render the component, leaving out its own file and the dev preview (`app/(dev)`).

**Status**

| Status     | Meaning                                                                                |
| ---------- | -------------------------------------------------------------------------------------- |
| adopted    | The one way this is built                                                              |
| partial    | It exists, but hand-written copies outnumber or rival it. The copy count is in the row |
| single-use | One consumer. Either the pattern is rare, or copies exist elsewhere                    |
| unused     | Nothing in production renders it                                                       |
| internal   | Used only by other files in `components/ui`                                            |
| duplicate  | A second implementation of another row                                                 |

Update the row when you add, merge or retire a component. The roadmap in [strategy.md](strategy.md) says which rows are due to change and in which batch.

layout and the same AlbumSlotTile actions as the grid.

## How the counts were taken

- Count command, run from the repo root for each name: rg -l -e '(^|[^\w.])<Name([ />]|$)' app components -g '*.tsx' -g '!app/(dev)/**', then drop the defining file, any file that declares its own local component of the same name, any file that imports a different component of the same name, and any file whose only match is in a comment. The leading guard removes TypeScript generics such as useState<Row | null>, which the plain '<Name[ />\n]' pattern would count. There are no test or spec files under app/ or components/, so no test exclusion was needed.
- Same-name adjustments made by hand: Notice is 66 + 2 (imported as NoticeBox in coverage/coverage-notice.tsx and menu-photos/item-photo-review.tsx) = 68. StatusChip is 45 JSX matches - 8 files that import the same-named wrapper from tasks/status-badges.tsx - 1 (tasks/status-badges.tsx itself, which renders its own wrapper) + 2 alias users (SystemChip in tasks/status-badges.tsx and tasks/task-summary.tsx) = 38. EvidenceThumb is 15 JSX matches - 3 files that import the separate EvidenceThumb from tasks/evidence-thumb.tsx (needs-another-photo-list.tsx, todo-list.tsx, submission-list.tsx) = 12. ProfileAvatar is 19 matches - 1 (common-room/post.tsx names it in a doc comment only) = 18. Field is 16 - 1 (local Field in library-filters.tsx) = 15; Frames 7 - 2 locals = 5; TallyItem 4 - 1 local = 3; ItemRow 3 - 1 local = 2.
- Copy counts use the same globs plus -g '!components/ui/**' -g '!components/nabalens/common-room/**' (exclusion globs must come after -g '*.tsx' or rg ignores them). Patterns: Card 'rounded-card[^"`]*shadow-card|shadow-card[^"`]*rounded-card' = 97 files; SectionHeader 'font-display[^"`]*text-section-title|text-section-title[^"`]*font-display' = 57; ScopeLabel 'font-mono[^"`]*text-meta-strong|text-meta-strong[^"`]*font-mono' = 6; IconDisc 'rounded-round' with 'size-(13|18)' = 2; Row 'grid-cols-\[auto_minmax\(0,1fr\)_auto\]' = 4 hits, of which components/nabalens/notice.tsx is the Notice layout, leaving 3; raw '<button\b' 16, 'buttonVariants' 59, '<label\b' 25, '<textarea\b' 6, '<table\b' 3, '<select\b' 1, 'aria-pressed' 6, 'type="radio"' 8 (plus 'role="radio"' buttons in coverage/requirement-setup.tsx and coverage/amenity-fact-form.tsx), 'type="checkbox"' 9, '<dl\b' 12, 'role="progressbar"|<progress\b' 3, 'size="icon' 12. These are same-line class matches, so they are lower bounds and some hits are legitimate variations rather than copies. Whether each buttonVariants use styles a link was not checked.
- Sub-part use in components/ui (files): Dialog Content 23, Title 23, Header 21, Footer 19, Description 16, Close 3; AlertDialog Content, Header, Title, Description, Footer and Cancel 10 each; Field Label 15, Error 14 (15 matches less the local FieldError in coverage/team-roster.tsx), Description 6, Set 2, Legend 2; DropdownMenu Trigger, Content and Item 4, Group, Label and Separator 1; Table Header, Body, Head, Row and Cell 2; Select Trigger, Content, Item and Value 1; ToggleGroupItem 1; Avatar Image and Fallback 1; AlertDescription 1.
