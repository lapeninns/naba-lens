# S5-PWA: FA-53, installable app

Spec §15.3, checklist row S15.3-pwa. Branch `fa/s5-pwa`, base `068f67d9e`.

## What was built

- **Web app manifest** (`app/manifest.ts`, served at `/manifest.webmanifest`
  as `application/manifest+json`): name and short name Naba-Lens, the
  layout's description, `id`/`start_url`/`scope` `/`, `display: standalone`,
  background and theme colour Album's light `canvas` (#f6f1e7). Static (no
  request-time API), so it is the same for everyone and holds no origin, key,
  address or account.
- **Icons** in Album colours: an N inside a lens ring, paper (#f6f1e7) on the
  Album green `accent` (#1d4d36). `public/icons/icon-192.png` and
  `icon-512.png` (purpose `any`, rounded square), `icon-maskable-512.png`
  (purpose `maskable`, full bleed, the mark well inside the 80% safe circle)
  and `app/apple-icon.png` (180 x 180, Next's `apple-touch-icon` link).
  Generated by `scripts/pwa/generate-icons.mjs` from paths (no font
  dependency); the PNGs are committed.
- **theme-color** for light and dark is now Album's `canvas` (#f6f1e7 /
  #151714); it was still Common Room's grey (#eef0f3 / #131415). Both values
  live in one module, `lib/pwa/canvas-colours.ts`, used by the layout and
  the manifest.
- **appleWebApp** metadata (`capable`, title Naba-Lens, status bar default)
  and `applicationName`.
- **Me › Help and account › Add to home screen**
  (`components/nabalens/me/install-app.tsx`, mounted in `MeAccount` after the
  Notices / If you can't add photos links):
  - Browsers that fire `beforeinstallprompt`: a card with an **Add to home
    screen** button that opens the browser's own prompt. Shown only while the
    browser offers it; answering spends the prompt, so it goes; it returns
    only if the browser fires the event again; once installed (accepted or
    `appinstalled`) it never returns.
  - iOS only (iPhone/iPod UA, or iPadOS's Mac-with-touch): three plain steps,
    "Tap Share (the square with an arrow). Tap Add to Home Screen. Tap Add."
  - Already standalone, or any other browser: nothing.
  - `InstallPromptCapture` (renders nothing) is mounted in `app/layout.tsx`
    so the module registers its listener on the first page load: Chrome fires
    `beforeinstallprompt` once per load, usually before anyone opens Me.
- **No service worker**, no new cache.

## Decisions taken (owner asleep; recommended option each time)

1. **Mark.** No Naba-Lens mark existed (`app/favicon.ico` is still the
   create-next-app default). I drew a simple one, an N in a lens ring, in
   Album paper on Album green. The owner may want to replace it; rerun the
   script after editing it. The favicon is left as it was (out of scope; an
   ICO can't be written by sharp). Suggest the next batch replace it.
2. **Capture in the root layout.** The brief asked for one component plus its
   mount line. Mounting only in Help would miss the event on nearly every
   visit (it fires on the first page load, and Me is reached by client
   navigation), so the same file also exports a no-op `InstallPromptCapture`
   mounted in `app/layout.tsx`. One extra line.
3. **Dismissed.** "Hides once dismissed" is read as: the spent prompt goes;
   a new `beforeinstallprompt` (the browser deciding to offer again) shows it
   again. Only an install hides it for good. Nothing is stored.
4. **Proxy skips the manifest.** Same as favicon and images: no Supabase
   session refresh or cookie work for it (`set-cookie` absent, checked in
   e2e). The icons are `.png` and were already skipped.
5. **Scope guard.** It counted metadata routes at their folder URL, so
   `app/manifest.ts` showed up as a handler at `/`. It now names a metadata
   route by the URL Next serves (`/manifest.webmanifest`, `/robots.txt`,
   ...), and `/manifest.webmanifest` is allowed explicitly with its reason.
   The guard is otherwise unchanged and still strict.
6. **Raw colours.** Kept the token-discipline allow-list at 35: the two
   layout entries moved to `lib/pwa/canvas-colours.ts` (with the new values)
   rather than adding a manifest entry and raising the cap.
7. **Copy.** British English, no status words, no camera wording; the staff
   copy guard and gallery guard scan `components/nabalens/me` and pass.
8. **iOS on other browsers.** Steps show on any iOS browser (they all share
   Safari's engine; iOS 16.4+ Chrome also has Add to Home Screen in Share),
   worded "in Safari" as the decision asks.
