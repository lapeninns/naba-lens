## Decisions to record (recommended options taken; the owner was asleep)

1. **V1:** a manager may set or clear only the **backup** reviewer. The main reviewer is admin-only (spec §7 M5, §8 A2), refused in the database (`main_reviewer_admin_only`) and shown read-only on the manager Venue screen. Checklist row M5-review-assignments ("Nominate a main and a backup reviewer") should say "nominate a backup reviewer; main is read-only".
2. **V2:** manager venue History hides admin-only account-security actions. The list is `private.venue_history_admin_only` (today only `mfa_reset`). Personnel rows (`account_*`) stay visible, as S2-MGR chose. I used a deny-list rather than an allow-list so no venue event that History shows today disappears; a new security action must be added to that function.
3. **K3:** slot change reports get their own Venue page, `/manager/venue/reports`, added to the scope guard's allow-list. The manager's actions are "Dealt with" (`resolved`) and "Dismiss" (`dismissed`), each with an optional note.
4. **K8:** reviewer candidates on the admin screen are the venue's managers only. Admins review every venue without being named.
5. **D3:** the manager phone tab labels scale below 17 px on narrow phones (departure A-R5-1).
6. **D2:** Button is capped at its container (`max-w-full`) everywhere.
