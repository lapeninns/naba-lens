## Decisions made (for the coordinator to record)

1. **R10-1 (W6):** a queued upload is identified by its File and its selection (`UploadContext.batchId`). A venue switch takes back every waiting queue item of each undone photo, so a photo matched again waits as its own new item and is reserved only at the venue it was matched for.
2. **R10-2 (W7):** one rule decides whether a retake is answered, for Home, Album's notes, Me and the slot page (`private.retake_answer`). **Cleared:** a photo of the slot was accepted after the retake was asked, by anyone (decision 4, append-only). **Retaken:** the person sent a newer image of the slot that is ready, not deleted, not set aside (Not used or Mark duplicate) and has no decision yet for that slot. Otherwise the retake is open. Place and facility retakes use the same two tests on their own decision tables.
3. **R10-3 (W7, behaviour change on Home):** a replacement set aside as Not used no longer answers a dish retake on Home: the note shows as open again. This matches Album, which already counted the slot as Needs another photo.
