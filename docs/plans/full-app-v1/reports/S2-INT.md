## Assumptions

- **A duplicate counts again once its original no longer does** (removed, or never accepted). A copy of an accepted original never covers any slot, including one the original never covered. Owner may want a decision in `decisions.md` (review R4 asked for one).
- **Reference photos stay in internal packages**, marked internal; they are never public or publishable. The hand-off said "never exportable"; internal packages already list unreviewed photos, so excluding only reference there would be incoherent.
- **A temporarily unavailable amenity** reads Check due as well when the resolver withholds its answer (existing B03 behaviour).
- **A Wi-Fi Yes without media still needs the redaction tick and test notes** (submit rules unchanged).
- **Catalogue version 2 bumps every key's `catalogue_version`** (the generator's rule), which records a definition change for every working slot. Only six evidence rules changed.
- **Admin upload is database only.** `my_venue_capabilities.canUpload` stays false for admins until a screen names a venue.
- **R24 is S2-FIX's.** `ops_venue_managers` is not redefined here. If S2-FIX resolves managers through `venue_role_of` per profile per venue, measure it: a per-profile `venue_role_of` over all venues took 72 s on the test stack.
