# S3-R15: Me's way to the older Add sheet, and the legacy e2e suites

Worker S3-R15, Sprint 3 integration. Branch `fa/s3-r15`, based on `efbf17117` (merge of S3-R14). Not pushed; no PR; no `lci` or `pnpm verify:release`.

This round answers S3-R12's "Blocking for integration" item. S3-R12 made Me's main button "Add photos" open the gallery and Match, like the tab bar. Match takes photos only, so Me had no general way to add a video, and about 19 e2e specs and helpers still clicked Me's old "Add photos or videos" to reach the older upload sheet.

## Decision to record (coordinator)

- **R15-1:** Me's main **Add photos** keeps opening the gallery and then Match (S3-R12, DESIGN.md §6.1). Before it, Me's header has a secondary **Add a video** button (DESIGN.md §5 Secondary button; `FilmStripIcon`, the app's existing video marker). It opens the older Add sheet (`openAdd({ dialog: true })`, the same call the old button made) for a video or anything else Match does not take. The sheet still takes photos as well, with "What's in these photos?" and per-file Retry. It is gallery first: no `capture` and no camera icon (the gallery guard passes). A blocked or paused venue shows neither button. The empty state still repeats only Add photos. The owner was asleep, so I took the option the brief recommended.
