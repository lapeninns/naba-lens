## Decisions made (for the coordinator to record)

1. **Suspend from use writes its own place and facility withdrawals (W8, W9).** It is an admin-only safety action that only reduces exposure. So the reviewer's guards (self-review, active and in-scope check) don't apply to it, and it never rolls back because one approval sits on an archived check. A withdrawal on an archived or out-of-scope check is recorded too, so the photo doesn't come back if the check is restored. This option comes from W9's proposed fixes ("a direct insert of the withdrawn decision under the same locks").
2. **Admins decide facility photos on an admin photo review (V18).** It is the manager's photo review at `/admin/coverage/{venue}/menu-photos/photo/{asset}`, scoped to that venue. The admin Review page lists facility photos under the place photos.
3. **The AppBar sections never shrink; the user name gives way.** Applies to every role from `md`.
4. **The e2e app sees exactly the job secrets the test run sees.** A local `.env.local` can no longer change which route specs apply.
