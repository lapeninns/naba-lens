# V2-A report: design system v2 foundation

Worker V2-A, 18 Nov 2026, branch `v2/a-foundation` (based on `fbe5d9f0c`). Decision [D10](../../../design-system/decisions.md); plan [plan.md](../plan.md); package [docs/design-system/v2/](../../../design-system/v2/README.md). Not pushed; no PR, deploy or `lci`.

## Approach (recorded choice)

- **Tailwind utilities on tokens, not `nl-` classes.** The app is Tailwind 4 with a strict token vocabulary (`tests/unit/token-discipline.test.ts`, `token-integrity.test.ts`) and one class merger (`lib/utils.ts`). Copying `components.css` would have created a second vocabulary beside it. Every v2 rule is written as utilities on tokens in `app/globals.css`, and each v2 component is the existing shared component restyled (the catalogue's v2 table names which). `tokens.css` and `components.css` are not copied into the app.
- **v2 values under v2 names, Album role names on top.** `app/globals.css` tier 1 holds v2's light and dark values (converted to OKLCH, the hex in a comment) under v2's names (`--paper`, `--bottle`, `--brass`, `--sky`, `--signal` ...). Tier 2 points every role name the code already uses (`canvas`, `surface-2`, `accent`, `ok-fg`, `warn-fg` ...) at a v2 value, so every screen took v2's colours with no screen edit. Roles are declared on `:root, .dark` together because the app has `.dark` subtrees (the photo viewer).
- **Theme switch unchanged:** next-themes' `.dark` class on `<html>` (follows the OS, Appearance setting). v2's `data-theme="dark"` is the same thing under another name.
- **Icons:** the app's Phosphor set stays (v2 uses Lucide only as a stand-in; adding a dependency was out of scope). v2's fixed meanings are applied where a component chooses an icon (check, clock, triangle, camera for a retake mark).

## Departures to record (V2-C, `departures.md`)

1. Staff tabs Album / Add photos / Me (v2: four tabs). Add photos uses v2's round button with the gallery icon, never a camera.
2. Empty SubjectCard shows "+ Add" (gallery), not v2's camera icon (D9).
3. Status words are FA-7's, not v2's table; each FA-7 state is mapped to a v2 tone in `status-chip.tsx`.
4. Button and PickChip `sm` stay 44px below `desktop:` (touch target guards); v2's 40px compact applies from 1100px.
5. Sheet buttons on phones keep the safe choice first in DOM and visual order (v2: primary first); reordering would split visual and focus order.
6. PickChip keeps a tick when on, beside v2's ink fill.
7. The manager phone tab bar label is v2's 13px caption at every width (replaces the old scaling label, departure A-R5-1).
8. Phosphor icons instead of Lucide.
