## Shared components touched (APIs kept, additions only)

- `components/ui/progress.tsx`: adds `size="lg"`, a 12px track (v2 `nl-cover__bar`). The contract table in `tests/ui/primitives-contract.test.tsx` gains the `lg` row and its wording.
- `components/nabalens/meta-list.tsx`: `MetaItem.labelHidden` keeps a label for screen readers only and lets the value span both columns.
- `components/nabalens/album/review/thumb-review.tsx` is in the album folder, but only the manager Review renders it.

## Not done, for V2-R or V2-C

- **Fixed DecisionBar.** The manager photo detail decides per slot: one photo can carry several dishes, places and amenities, each with its own Approve. A single bar fixed to the bottom would change the flow, so each slot keeps its own buttons, styled as a DecisionBar strip. Their order is still Approve, Keep as reference, Ask for another photo, Fix label (v2 puts Fix label second); reordering them would change focus order. Review in a thumb already pins its one Accept / Ask again pair.
- **VenueBar in the shell header.** The manager header still writes the venue name itself (surface, a line under it, the full name wrapping to two lines). It also holds the wordmark below 1100px, Add, the account control and Log out, which `VenueBar` cannot hold, and MG-23 tests its `data-slot="venue-name"` clamp. Using the component would need a new VenueBar slot. That is left to V2-C or V2-R, as a departure or a VenueBar variant.
- **CoverageMeter legend chips.** `CategoryRow` carries only covered and total, so the meter has one segment. Waiting and needs-replacing counts would need a data change, and a "{n} covered" chip would add words.
- `SectionHeader` (common-room) is inset 4px from the page title (visible on Team). This is a shared component and was left alone.
- Shared folders that admin also renders (`coverage/`, `menus/`, `metrics/`, `search/`) still have `font-bold`. They were left for V2-B3 to avoid conflicting edits.
