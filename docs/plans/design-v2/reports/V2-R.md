### Shared components changed (API kept)

- `Button`: `sm` is 48px unless inside `data-density="compact"`. The variants, sizes and props are the same.

- `Dialog` Close: size `md`.
- `SideNav`: the outer element is now the `<nav>`. `data-slot="side-nav"` moved to it, and the unused `side-nav-rail` slot is gone.
- `AddTrigger`: new `kind="compact"`. Existing kinds are kept.
